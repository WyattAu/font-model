# font-model
[![Estate integration](https://github.com/WyattAu/estate-integration/actions/workflows/ci.yml/badge.svg)](https://github.com/WyattAu/estate-integration/actions/workflows/ci.yml)
[![crates.io](https://img.shields.io/crates/v/font-model.svg)](https://crates.io/crates/font-model)

Editable in-memory font model for Rust: glyph outlines, cmap formats 4 and 12,
metrics, validation, and subsetting.

Part of the WyattAu kit estate text stack, exercised by the
[font-conformance](https://github.com/WyattAu/font-conformance) differential
oracle and the [estate-integration](https://github.com/WyattAu/estate-integration)
composing suite.

## Install

```toml
[dependencies]
font-model = "0.1"
```
